# CutFlow updates

แหล่งดาวน์โหลดอัปเดตโปรแกรม CutFlow

## เวอร์ชัน 0.5.0

เพิ่มระบบตรวจสอบและติดตั้งอัปเดตผ่าน GitHub Releases โดยใช้โปรแกรมพื้นฐานเวอร์ชัน 0.4.9

ไฟล์สำหรับแต่ละ Release:
- `CutFlow-update.zip`
- `CutFlow-update.zip.sha256`

เครื่องที่ใช้เวอร์ชัน 0.4.9 หรือต่ำกว่าต้องติดตั้งชุด CutFlow 0.5.0 ด้วยตนเองครั้งแรกก่อนใช้ระบบอัปเดต

ตรวจสอบโครงสร้างไฟล์มาร์คกับไฟล์อ้างอิงแล้ว แต่ยังไม่ได้ยืนยันผลตัดจริงบนเครื่อง Graphtec หรือทดสอบระบบอัปเดตครบวงจรบน Windows
