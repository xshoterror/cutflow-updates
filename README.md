# CutFlow updates

แหล่งอัปเดตโปรแกรม CutFlow

## เวอร์ชันล่าสุด: 0.5.8

### เพิ่มใน 0.5.8
- มีทั้งแพ็กเกจอัปเดตและแพ็กเกจเต็มสำหรับติดตั้งใหม่ พร้อม SHA-256
- ใช้แพ็กเกจ paper-test ที่ยืนยันว่าใช้งานได้ โดยไม่เปลี่ยน Registration Mark หรือ Native SA
- กำหนดขนาดกระดาษเองได้ กว้าง × สูง (cm) และสลับแนวกระดาษได้

ระบบอัปเดตของ CutFlow ใช้ไฟล์:
- `CutFlow-update.zip`
- `CutFlow-update.zip.sha256`

SHA-256 ของแพ็กเกจ v0.5.8:
`10ad075dc3af07518bdc346fb94b7264dbd522c954920d8eefb533483b78a34c`
